4. RULES
1. Use vanilla JavaScript only.
2. Use the suggested public exchange-rate API or another documented public exchange-rate API.
3. Do not hardcode exchange rates as the main source of conversion data.
4. Validate user input before performing a conversion.
5. Handle network errors, invalid responses, and missing currency rates.
6. Do not use React, jQuery, Bootstrap, Tailwind, or other frameworks.
7. Do not expose API keys or sensitive information.
8. Write and understand the code yourself.
9. Do not leave uncaught browser console errors.
