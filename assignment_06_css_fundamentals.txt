-----------------------------

[ ] Give each box a width or max-width.
[ ] Apply padding inside each box.
[ ] Apply margin outside each box.
[ ] Add a border.
[ ] Change one box's padding and observe the difference.
[ ] Write two or three sentences explaining the difference between margin
    and padding.

DESIGN REQUIREMENTS
-------------------
- Use a consistent palette with no more than four main colors.
- Ensure text is readable against its background.
- Keep spacing consistent.
- Use meaningful class names such as .profile-card or .section-title.
- Avoid unnecessary inline styles.
- Do not use Bootstrap, Tailwind, or another CSS framework.
