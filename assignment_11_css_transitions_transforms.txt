CSS Transitions, Transforms, Hover Effects & Interactive UI Polish




TASK REQUIREMENTS

A. HTML Structure
[ ] Create index.html.
[ ] Add a header with a logo or brand name.
[ ] Add a navigation menu with at least 3 links.
[ ] Create a hero section with a heading, description, and call-to-action.
[ ] Add at least 3 product/service cards. Each needs a title, description, price/key detail, and action link/button.
[ ] Add a footer with copyright text and at least 2 useful links.
[ ] Use semantic HTML elements where appropriate.

B. CSS Styling & Layout
[ ] Create a separate style.css and link it correctly.
[ ] Use a consistent palette of 3–5 main colors.
[ ] Use readable typography, spacing, borders, and shadows.
[ ] Use Flexbox or CSS Grid for the main layout.
[ ] Establish clear visual hierarchy and keep the page uncluttered.

C. CSS Transitions 
Apply smooth transitions to at least 4 different elements:
[ ] Buttons change color/background on hover.
[ ] Product cards change shadow or border on hover.
[ ] Navigation links change color on hover.
[ ] Images/icons smoothly scale or change opacity.
Use transition properties such as:
transition: transform 0.3s ease, box-shadow 0.3s ease;

D. CSS Transforms 
Use at least 3 appropriate transform effects:
[ ] A card lifts slightly with translateY().
[ ] A product image gently scales with scale().
[ ] An icon or decorative element rotates with rotate() if suitable.
[ ] Keep effects subtle and avoid making text hard to read.
Example:
.product-card:hover {
    transform: translateY(-6px);
}

E. Hover, Focus & Accessibility 
[ ] Add :hover styles to links and buttons.
[ ] Add :focus-visible styles for keyboard users.
[ ] Ensure text/background contrast is readable.
[ ] Add descriptive alt text to meaningful images.
[ ] Include a prefers-reduced-motion media query to reduce/disable nonessential motion.
[ ] Do not hide essential information behind hover effects; keep controls usable on touchscreens.

F. Responsive Design & Quality 
[ ] Test around desktop width (1280px), tablet width (768px), and mobile width (375px).
[ ] Rearrange/stack cards on small screens.
[ ] Prevent horizontal scrolling and overlapping content.
[ ] Check all text, images, and buttons fit properly.

G. Code Quality 
[ ] Use clear class names and consistent indentation.
[ ] Avoid unnecessary repeated CSS.
[ ] Add comments for important sections.
[ ] Keep HTML and CSS separate.
[ ] Check for broken links and obvious browser errors.

3. REQUIRED FILE STRUCTURE

day11-product-showcase/
|-- index.html
|-- style.css
|-- images/ (optional)
|-- README.txt

README.txt must include:
- Project title and chosen theme
- Features implemented
- How to run the project
- At least 3 CSS effects used and what each does

4. RULES
1. Use only HTML and CSS. Do not use JavaScript, Bootstrap, Tailwind, or other frameworks.
2. You may use a small number of royalty-free images or simple CSS shapes.
3. Do not copy an entire ready-made template; build the layout yourself.
4. Keep animations smooth and subtle.
5. The page must remain usable without hovering.
