React TypeScript Fundamentals — Type Safety, Interfaces, Props & State

PROJECT: React Student Management Dashboard

Build a React Student Management Dashboard using TypeScript. Display student records, allow users to add and edit students, search and filter the list, and show basic statistics. Focus on understanding TypeScript in React and using types to make components and application logic safer.

A. TYPESCRIPT PROJECT SETUP
[ ] Understand the difference between JavaScript and TypeScript.
[ ] Create a React project using Vite with the TypeScript template.
[ ] Explore .ts and .tsx file extensions.
[ ] Understand the purpose of tsconfig.json.
[ ] Start the development server and verify the project runs.
[ ] Understand basic types: string, number, boolean, arrays, and objects.
[ ] Use type annotations for variables and function parameters.
[ ] Understand optional properties and union types.

B. INTERFACES AND TYPE ALIASES
[ ] Create a Student interface with ID, name, email, course, and enrollment status.
[ ] Create a type alias for enrollment status using a union type.
[ ] Create an interface for form input values.
[ ] Create an interface for dashboard summary statistics.
[ ] Understand when to use an interface and when to use a type alias.
[ ] Use optional properties where a field is not always required.
[ ] Avoid using any unless there is a clear reason.

C. TYPED REACT COMPONENTS AND PROPS
[ ] Create reusable components for Header, StudentCard, StudentList, StudentForm, and SummaryCards.
[ ] Define interfaces or types for component props.
[ ] Pass student data to StudentCard using typed props.
[ ] Type callback props for add, edit, and delete actions.
[ ] Use React.ReactNode for component children when appropriate.
[ ] Use optional props and default values where needed.
[ ] Ensure TypeScript reports no prop-related errors.

D. TYPED STATE AND EVENT HANDLING
[ ] Use useState<Student[]> for the student list.
[ ] Use appropriate types for selected student and form state.
[ ] Type input change handlers using React event types.
[ ] Type form submission handlers correctly.
[ ] Add a new student using a typed function.
[ ] Edit an existing student's details.
[ ] Delete a student using the student's ID.
[ ] Update state immutably without directly mutating the student array.

[ ] Add a form to create a student.

F. GENERICS AND REUSABLE UTILITIES

[ ] Create a generic function that returns an item by ID from an array.

G. PERSISTENCE AND CODE QUALITY
[ ] Save student records in localStorage.

4. RULES

1. Build the application using React with TypeScript and Vite.
2. Use .tsx for React components and .ts for non-JSX TypeScript files.
3. Define clear interfaces or type aliases for application data.
4. Type component props, state, event handlers, and important functions.
5. Use useState with appropriate types.
6. Do not use any to bypass TypeScript errors.
7. Do not directly mutate React state.
8. Keep types and reusable utility functions separate from UI components.
9. Use localStorage to persist student records.
10. Do not use a backend or external API for this assignment.
11. Do not use a UI component framework.
12. Ensure the project builds without TypeScript errors before submission.
