PART A — CSS GRID FUNDAMENTALS
------------------------------
Create a section containing at least six cards in a grid.

[ ] Use display: grid on the parent container.
[ ] Use grid-template-columns to define columns.
[ ] Use gap for consistent row and column spacing.
[ ] Give each card a heading and short description.
[ ] Try grid-template-columns: repeat(3, 1fr) on a wide screen.
[ ] Use a media query to reduce columns on smaller screens.
[ ] Keep cards aligned and readable.
[ ] Compare the grid layout with your Flexbox card layout from Day 7.

PART B — CSS POSITIONING
------------------------
Create a demonstration section showing these positioning types.

[ ] static — observe normal document flow.
[ ] relative — move an element slightly from its normal position.
[ ] absolute — position a small label inside a parent with position: relative.
[ ] fixed — create a small help or contact link near a viewport corner.
[ ] sticky — create a heading or navigation element that sticks while scrolling,
    if appropriate for your page.

IMPORTANT:
- Positioning should not cover important text or navigation.
- Keep fixed and sticky elements small and usable.
- A positioned element often needs a suitable containing parent.
- Test by scrolling and resizing the browser.

- Main content: welcome heading and summary.
- At least three statistics cards, such as Total Students, Courses, and Events.

Requirements:

[ ] Use consistent spacing, colors, typography, and borders.
