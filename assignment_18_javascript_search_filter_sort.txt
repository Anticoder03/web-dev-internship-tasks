4. RULES
1. Use HTML, CSS, and vanilla JavaScript only.
2. Use the JSONPlaceholder users API for the displayed records.
3. Do not hardcode the user cards or company options.
4. Perform search, filtering, and sorting on the fetched data in JavaScript.
5. Use event listeners rather than inline HTML event attributes.
6. Do not use React, jQuery, Bootstrap, Tailwind, or other frameworks.
7. Do not use a backend or database for this assignment.
8. Handle loading, errors, and empty results properly.
9. Do not leave browser console errors.
