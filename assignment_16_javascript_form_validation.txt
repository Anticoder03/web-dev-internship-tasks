4. RULES

1. Use vanilla JavaScript only.
2. Use JavaScript for the main form validation logic.
3. Use event listeners instead of inline HTML event attributes.
4. Use event.preventDefault() to handle form submission with JavaScript.
5. Do not use alert() as the main way to display validation messages.
6. Do not send or store real personal information.
7. Do not use a backend or database; this is a frontend-only practice form.
8. Write and understand the code yourself.
9. Do not leave browser console errors.
